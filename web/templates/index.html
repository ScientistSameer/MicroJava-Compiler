MicroJava Compiler Help

About

This is a full MicroJava mini-compiler built for CS-471L CC Lab Final Term Project at UET Lahore by Sameer Babar. It includes:

  • Lexer — tokenizes MicroJava source with double buffering
  • Recursive Descent Parser — builds an AST with error recovery
  • LL(1) Predictive Parser — table-driven with FIRST/FOLLOW sets
  • SLR(1) LR Parser — shift-reduce with automatic table construction
  • Symbol Table — hash-based with nested scope support
  • Semantic Analyzer — type checking and scope verification
  • TAC Generator — three-address code with constant folding + DCE
